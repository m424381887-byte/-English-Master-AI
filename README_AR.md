# English Master AI – معلم الإنجليزية الذكي

هذه نسخة أولية عملية (PWA) تعمل على Android والكمبيوتر.

## تشغيلها
1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى استضافة HTTPS ثابتة (مثل GitHub Pages أو Cloudflare Pages) أو شغّلها محلياً عبر خادم محلي.
3. افتح رابط `index.html` في Chrome.
4. اختر «تثبيت التطبيق» من قائمة المتصفح أو زر التثبيت الذي يظهر عند دعم المتصفح.

> ملاحظة: لا يعمل تثبيت PWA وService Worker عادةً من `file://` مباشرة؛ يلزم HTTPS أو localhost.

## الموجود في هذه النسخة
- واجهة عربية متجاوبة.
- درس تمهيدي بخمس كلمات وجمل وقاعدة واختبار.
- نطق الكلمات عبر Speech Synthesis إذا كان متاحاً في الجهاز.
- مدرب محادثة محلي قائم على قواعد تعليمية أولية.
- التعرف على الكلام إذا كان المتصفح يدعمه.
- مراجعة كلمات، نقاط، تقدم، وحفظ محلي.
- دعم العمل دون اتصال بعد تحميل الملفات أول مرة، عبر Service Worker.

## حدود النسخة الحالية بصراحة
- ليست بعدُ معلماً يعتمد نموذجاً لغوياً كبيراً؛ الردود الحالية محلية ومحدودة بأمثلة وقواعد بسيطة.
- التعرف على الكلام قد يحتاج اتصالاً بالإنترنت ويختلف حسب المتصفح.
- جودة الأصوات المتاحة تعتمد على الأصوات المثبتة في الجهاز.
- لا يوجد حالياً تقييم صوتي دقيق للفونيمات أو تحليل طلاقة احترافي.
- المنهج الحالي يحتوي على الدرس الأول فقط؛ بقية مستويات A0–C2 تحتاج إلى بناء المحتوى والاختبارات تدريجياً.
- لا توجد خدمة ذكاء اصطناعي سحابية مجانية غير محدودة مضمونة؛ لم تتم إضافة أي API مدفوعة أو مفاتيح سرية.

## التطوير التالي
1. إضافة منهج كامل A0 ثم A1 مع عشرات الوحدات.
2. حفظ جدول مراجعة متباعدة حقيقي لكل كلمة.
3. ربط نموذج لغوي محلي أو استضافة مجانية متاحة دون افتراض أنها غير محدودة.
4. إضافة اختبارات استماع ونطق ومحادثات سيناريوهات.
5. إضافة تصدير واستيراد نسخة احتياطية للتقدم.
